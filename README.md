# YouTube Watch Later Quick Actions

Минимальное Chrome MV3-расширение для YouTube: быстрые действия в `Watch Later` и скачивание субтитров одной кнопкой на странице видео.

## Установка

1. Откройте `chrome://extensions`.
2. Включите `Developer mode`.
3. Нажмите `Load unpacked`.
4. Выберите эту папку: `youtube-watch-later-quick-actions`.

## Что добавляет

### Watch Later (`https://www.youtube.com/playlist?list=WL`)

- Иконка цепочки копирует `https://youtu.be/<videoId>`.
- Иконка корзины нажимает штатный пункт удаления YouTube, проверяя, что он относится к выбранному видео в Watch Later.
- Цвет иконок берётся из текущей темы YouTube.

### Субтитры на странице видео (`/watch`)

Кнопка «CC со стрелкой» в панели плеера, рядом с кнопками субтитров и настроек. Одно нажатие:

1. выключает звук;
2. включает субтитры на языке оригинала (по оригинальной аудиодорожке, автодубляж игнорируется), иначе английские;
3. берёт субтитры из собственного запроса плеера и скачивает `Название [videoId].transcript.txt`;
4. возвращает плеер в прежнее состояние (звук, пауза/воспроизведение, субтитры).

Формат файла: строка `YOUTUBE-SOURCE TRANSCRIPT`, строка JSON с метаданными и проверками (язык и тип субтитров, число фрагментов, конец последней реплики, длительность, `needs_tail_review`, описание видео), `---`, затем текст с метками `[M:SS]` каждые 15 секунд.

Из консоли или автоматизации:

```js
await wlqaTranscript.run()                      // скачать файл
await wlqaTranscript.run({ mode: "page" })      // заменить страницу текстом (для чтения агентом)
await wlqaTranscript.run({ mode: "return" })    // только вернуть результат, поле text
await wlqaTranscript.run({ preferredLang: "ru" })
```

### Если что-то перестало работать

YouTube периодически меняет плеер. Все шаги пишутся в консоль браузера с префиксом `[WLQA transcript]` (DevTools → Console, фильтр `WLQA`): `1/6 player ready`, `2/6 caption tracks`, `3/6 mute + enable captions`, `4/6 caption request found`, `5/6 captions parsed`, `6/6 output`. При ошибке выводится шаг, на котором всё сломалось, и подсказка, что именно могло измениться (селектор плеера, API субтитров, формат json3). Если кнопка не появилась, в консоли будет предупреждение со списком проверенных селекторов, а `wlqaTranscript.run()` можно вызвать вручную.

После обновления файлов нажмите перезагрузку расширения в `chrome://extensions` и обновите вкладку YouTube. Проверка логики: `node --test content.test.cjs transcript.test.cjs`.
